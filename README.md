# Argus

## Problem Statement

Argus is a real-time mule account detection system based on temporal transaction graphs.

The goal is to identify suspicious accounts by analyzing:

- Transaction behavior
- Graph connectivity patterns
- Temporal money flow
- Network-level anomalies

## Planned Architecture

1. Data Generation
2. Graph Construction
3. Feature Engineering
4. Machine Learning
5. Risk Scoring
6. Visualization Dashboard
